# Voxelcraft
A browser based block game

Controls are:
W A S D to Move
Shift to	Sprint
C to	Crouch
Space to	Jump or swim
Left mouse to	Mine or attack
Right mouse to	Place, eat, open chests and doors, use tables or furnaces
E opens	Inventory and crafting
V is	Third-person view
F	to Fly (Creative)
1–9 to	Select hotbar slot
Mouse to wheel	Cycle hotbar
Esc to	Pause

Mostly made by Claude, directed and tested by me.
